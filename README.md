# Euclid Lab — 从公设到定理

通过积木式几何构造和严格的规则验证，逐步学习欧几里得几何。

**在线体验：** https://yangjunjun.github.io/Euclid_Lab/

## 15 个递进关卡

| 关卡 | 主题 | 学习目标 |
|---|---|---|
| 01 | 连接两个点 | 第一公设 |
| 02 | 画出第一个圆 | 第三公设 |
| 03 | 双圆相交 | 交点构造 |
| 04 | 证明等边三角形 | 圆的定义、相等传递 |
| 05 | 让证明变成工具 | 复用命题 I.1 |
| 06 | 圆上的等距点 | 圆上点与半径 |
| 07 | 发现第二个交点 | 双圆的两个交点 |
| 08 | 同圆的两条半径 | 相等关系传递 |
| 09 | 证明一个菱形 | 四边相等与定义 |
| 10 | 向前延长线段 | 第二公设、点的顺序 |
| 11 | 向另一侧延长 | 反向延长 |
| 12 | 线段加法 | 整体等于部分之和 |
| 13 | 从圆复制一段距离 | 射线与圆相交、半径相等 |
| 14 | 构造两倍线段 | 线段加法、相等代换 |
| 15 | 证明一个中点 | 居间关系、等距定义 |

积木操作：点击或拖拽到 STEP BUILDER，配置几何点、圆与前提关系，点击「应用积木」。每一步都在右下的「推理记录」中保留可追溯的推理依据。支持画布拖动、撤销、重置、提示以及本地通关进度。

## 数学范围与边界

这是**有限规则集的教学型证明系统**，而不是《几何原本》全部命题的完整形式化。项目额外使用圆的定义、两圆交点存在条件、圆-射线相交规则、点的居间关系以及长度相等的传递性。

- 屏幕坐标与浮点运算用于构造和绘图，**不会直接把视觉上相等当作数学证明**。
- 每个证明结论都要求对应的构造前提或者已证明的事实。
- 第 5 关复用的等边三角形构造来自第 4 关的通关解锁。
- 第 9、14、15 关分别检验四边相等、线段加法与中点定义。
- 当前使用明确受限的构造规则，不声明支持任意欧氏命题的自动证明。
